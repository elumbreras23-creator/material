Identificar componentes antes de desmontar

Guía de investigación para aprender a leer etiquetas, reconocer modelos y buscar fichas técnicas fiables de una fuente ATX, un disco, una memoria RAM, una placa base y un procesador.

Laboratorio de taller · Sin registro

Objetivo de la práctica

Antes de completar el inventario del equipo, cada pareja debe localizar un identificador verificable de cada componente y consultar sus especificaciones. No se trata de adivinar características por su aspecto.

1 · LocalizaBusca una etiqueta, serigrafía o pantalla de información del sistema.
2 · TranscribeCopia exactamente la marca y el modelo o P/N. No confundas modelo y número de serie.
3 · InvestigaBusca el modelo entre comillas, preferentemente en la web del fabricante.
4 · ContrastaCompara al menos dos datos de la ficha técnica con el componente real.
5 · RegistraAnota evidencia, enlace consultado y aquello que no has podido confirmar.
Seguridad: apaga, desconecta el cable de corriente y sigue el procedimiento ESD de tu taller. No abras una fuente de alimentación ni manipules su interior. No retires el disipador solo para leer el procesador: primero intenta identificarlo por software o UEFI. No publiques números de serie ni fotografías con datos personales.

Buscador guiado de fichas técnicas

Escribe el fabricante y modelo exacto que hayas copiado. El botón abre una búsqueda web; esta página no envía la etiqueta a ningún servidor por sí sola.

Ejemplos de consulta: "modelo exacto" datasheet, "modelo exacto" site:dominio-fabricante.com. Si no hay coincidencia, elimina revisiones o guiones con cautela; comprueba que no has encontrado un modelo diferente.

¿Conviene buscar por fotografía? La foto es útil para leer o reconocer visualmente el producto, especialmente si la etiqueta está deteriorada. Pero para confirmar características suele ser más fiable copiar la referencia exacta y consultar la ficha oficial. Si utilizas una herramienta de búsqueda visual o IA, oculta el número de serie y verifica la respuesta con el fabricante.

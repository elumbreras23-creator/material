1. En el repositorio GitHub Pages, crea una carpeta llamada "taller" en la misma raíz en la que tienes "publicaciones".
2. Sube el archivo ensamblado-equipos.html y la carpeta imagenes/ completa, conservando las rutas.
3. Abre: https://elumbreras23-creator.github.io/material/taller/ensamblado-equipos.html
   Esta ruta presupone que tu proyecto se publica bajo /material/.
   Si el repositorio publica desde la raíz del dominio, adapta la ruta.
4. Para incluirlo en el listado JSON de tu web, añade un objeto con la URL relativa que corresponda a la ubicación de tu índice.

El HTML es independiente: no usa frameworks, CDN ni conexión a bases de datos.
Guarda marcas de tareas y cuaderno en el navegador local.
No entrega resultados automáticamente al profesor; el alumno descarga su registro .txt.

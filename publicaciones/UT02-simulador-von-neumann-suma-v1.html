Máquina de Von Neumann: sumar dos datos y guardar el resultado

Simulación básica con direccionamiento directo: cada dirección de operando indica la celda donde está el dato. Buses de direcciones y datos de 8 bits. Avanza paso a paso para observar cada transferencia.

Instrucción didáctica: SUM [80h], [81h] → [82h]. El programa ocupa cuatro bytes: 30h (operación SUM), 80h (dirección A), 81h (dirección B) y 82h (destino). La CPU lee primero esos cuatro bytes y después los operandos. No hay direccionamiento indirecto.

El bus de direcciones selecciona la celda (8 bits = 256 direcciones). El bus de datos transporta un byte (8 bits). El bus de control indica el tipo de operación.

Memoria principal (RAM)

Las instrucciones y los datos comparten la misma memoria.

DirecciónContenido (hex / bin)Significado

Las direcciones 10h–13h contienen la instrucción. Las direcciones 80h–82h contienen sus operandos y resultado.

Una celda de memoria contiene un byte. En este ejemplo se usan valores de 0 a 255 y una suma de 8 bits. Si A + B supera 255 se conserva el byte menos significativo y se activa el indicador de acarreo (C).

Preparado

¿Qué es direccionamiento directo?

La instrucción contiene la dirección exacta de la celda que guarda el dato. Por ejemplo, 80h significa leer MEM[80h]. No significa leer una dirección almacenada dentro de MEM[80h].

¿Y el indirecto o el inmediato?

Indirecto: una celda contiene otra dirección que hay que seguir para encontrar el operando. Inmediato: el dato aparece dentro de la instrucción, sin necesitar una lectura adicional del operando desde RAM.

Tu misión

Realiza una suma guiada y después una resta construyendo el programa. No basta con obtener el resultado: explica cómo llega cada instrucción y cada dato a la CPU.

Todos los valores de memoria se expresan en hexadecimal. M1 y M2 son datos de la misma RAM. Cada palabra contiene 16 bits; el acumulador opera con los 8 bits inferiores.

1. Qué significa la RAM en este modelo

Dirección
Es la posición de memoria a la que apunta el bus de direcciones. Por ejemplo: 20.
Contenido HEX
Es lo que hay guardado en esa posición. Por ejemplo: 00 05 o 10 20.
Contenido BIN
Es el mismo contenido, pero escrito en binario para ver los bits.
Interpretación
Indica si esa posición contiene una instrucción (por ejemplo LOAD 20) o un dato (por ejemplo M1[20] = 05 o M2[21] = 03).

En esta versión la memoria se lee por palabras. Cada posición contiene una palabra de 16 bits: 8 bits para el código de operación y 8 bits para el operando o dato.

2. Programa en RAM

Cada instrucción ocupa una sola palabra de 16 bits. Se divide en dos mitades: opcode (qué hacer) y operando (a qué dirección ir). LOAD, ADD, SUB y STORE usan direccionamiento directo. LDI usa un valor inmediato; HALT ignora el operando.

5. Memoria RAM: ahora separada y más clara

Cada fila representa una posición de memoria. Dirección = número de la fila. Contenido HEX = lo que hay guardado. Interpretación = cómo debemos leer ese contenido: como instrucción o como dato.

Decisión didáctica adoptada: para que una sola posición de memoria contenga una instrucción completa con direccionamiento directo, esta versión usa palabras de 16 bits (opcode + operando). Eso simplifica mucho la lectura del modelo.

La CPU sigue trabajando con un acumulador de 8 bits y la ALU realiza las sumas y restas módulo 256. El objetivo es pedagógico, no reproducir una CPU comercial real.

¿Qué estamos diagnosticando?

El diagnóstico separa CPU, ventilador, disipador, pasta térmica, temperatura y alimentación de la placa.

Seguridad y actualización: No cambiar voltajes manualmente siguiendo las cifras de 3,3 V o 5 V del PDF; pertenecen a plataformas antiguas y podrían dañar procesadores actuales.

Procedimiento paso a paso

  1. Anotar cuándo se produce el fallo: reposo, arranque o carga.
  2. Consultar temperatura, frecuencias y carga en BIOS/UEFI o software fiable. Ver cómo realizar las medidas paso a paso ↓
  3. Con el equipo apagado, comprobar que el disipador está fijado y el ventilador conectado a CPU_FAN.
  4. Revisar obstrucciones de polvo y ventilación del chasis.
  5. Verificar límites térmicos del modelo específico, sin aplicar un umbral universal.
  6. Si es necesario y está indicado, desmontar el disipador y renovar pasta térmica siguiendo el manual; repetir prueba.
  7. Contrastar con RAM, placa y fuente antes de concluir que la CPU está averiada.

Paso 2 · Cómo medir la temperatura de la CPU

Vamos a comparar dos situaciones distintas: una lectura en BIOS/UEFI, con el sistema operativo sin arrancar, y una lectura desde Windows, mientras el equipo está funcionando. No tienen por qué dar el mismo resultado: la carga y la gestión de energía cambian.

A · Medir desde BIOS/UEFI (sin instalar programas)

  1. Guarda tu trabajo y reinicia el equipo. En muchos ordenadores de sobremesa, pulsa repetidamente Supr/Del o F2 cuando aparece el logotipo. La tecla exacta depende del fabricante; en algunos portátiles la temperatura ni siquiera se muestra.
  2. Busca un apartado como Monitor, Hardware Monitor, H/W Monitor, PC Health Status o Fan Control. Puede encontrarse en el modo avanzado (Advanced Mode).
  3. Localiza CPU Temperature o CPU Package Temperature y anota el valor en °C. Si aparece, registra también CPU Fan Speed (RPM).
  4. Espera unos 2–3 minutos observando si la temperatura se estabiliza o aumenta continuamente. No cambies voltajes, frecuencias ni perfiles de ventilación.
  5. Sal mediante Exit / Discard Changes o Exit Without Saving, según el firmware, para no aplicar cambios accidentales.

Ejemplo de referencia: las UEFI ASUS incluyen información de temperatura y ventiladores en su pantalla y/o sección Monitor; otros fabricantes utilizan nombres y menús diferentes.

B · Medir en Windows con HWiNFO Portable

HWiNFO es una herramienta de diagnóstico y monitorización de sensores. Su modalidad Portable permite utilizarla sin el asistente habitual de instalación. Resulta adecuada para una práctica desde una carpeta local o una memoria USB, siempre que el equipo permita ejecutarla.

  1. Accede a la página oficial de descargas de HWiNFO ↗ y selecciona la opción Portable (no Installer).
  2. Descarga el archivo comprimido .zip y extráelo en una carpeta del ordenador o del USB. No ejecutes el programa directamente dentro del ZIP.
  3. En un equipo Windows habitual de 64 bits (x64), ejecuta HWiNFO64.exe desde la carpeta extraída. Para otras arquitecturas, elige la versión correspondiente que venga en el paquete. Windows puede solicitar permiso de administrador.
  4. Activa Sensors-only (solo sensores) al iniciar, si se ofrece, o abre la ventana Sensors desde la aplicación.
  5. Localiza el bloque del procesador y busca CPU Package, CPU (Tctl/Tdie) o temperaturas de núcleos (Core Temperatures), según el modelo. No confundas la temperatura de la CPU con la de la placa base.
  6. Observa las columnas Current (actual), Minimum (mínima), Maximum (máxima) y, si aparece, Average (media). Registra la temperatura en reposo y después de una tarea cotidiana breve y supervisada, sin forzar el equipo.
  7. Comprueba también la frecuencia del procesador (MHz/GHz) y las RPM del ventilador si el sensor las ofrece. Para el porcentaje de uso, puedes consultar el Administrador de tareas de Windows (Ctrl + Mayús + Esc → Rendimiento → CPU).
Portable no significa «arrancable»: HWiNFO se ejecuta dentro de Windows y puede guardarse en un USB, pero no sirve por sí solo para iniciar un ordenador sin sistema operativo.

Cómo interpretar lo que observas

Importante: no hay una temperatura única que sirva como límite para todas las CPU. Consulta la documentación del procesador o del fabricante del equipo. Valores elevados, caídas bruscas de frecuencia, apagados o errores de ventilador justifican ampliar el diagnóstico. La BIOS suele mostrar una lectura sin carga de trabajo real, y Windows permite observar la evolución durante el uso.

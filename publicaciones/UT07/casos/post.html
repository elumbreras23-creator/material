¿Qué estamos diagnosticando?

POST comprueba componentes durante el arranque. La interpretación es específica del firmware y la placa.

Seguridad y actualización: Una tarjeta POST PCI/PCIe/USB no siempre es compatible con la plataforma o expone información útil.

Material y herramientas

Manual placa/BIOSTarjeta POST compatibleRegistro de código

Procedimiento paso a paso

  1. Contar pitidos o secuencia luminosa completa; grabar el patrón si está permitido.
  2. Buscar el modelo exacto de placa y fabricante de firmware.
  3. Consultar la tabla del fabricante para ese equipo.
  4. Relacionar el código con RAM, CPU, GPU, alimentación u otros bloques.
  5. Realizar una comprobación dirigida, desconectando antes de manipular piezas.
  6. Repetir arranque y registrar si desaparece o cambia el código.
